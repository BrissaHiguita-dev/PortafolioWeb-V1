# 🌐 Portafolio Web Personal

Este proyecto consiste en un portafolio web personal interactivo, desarrollado para presentar de manera profesional mi perfil, experiencia laboral, formación académica, habilidades y proyectos.

El sitio cuenta con un diseño moderno, responsive e interactivo, permitiendo una correcta visualización en diferentes dispositivos como computadores, tabletas y teléfonos móviles.

Además, incluye diferentes funcionalidades que mejoran la experiencia del usuario, como animaciones, navegación entre secciones, contenido interactivo y un sistema de contacto integrado.

---

## 👩‍💻 Sobre el proyecto

El portafolio fue desarrollado utilizando tecnologías web como HTML, CSS y JavaScript.

Su objetivo principal es centralizar y presentar mi información profesional de forma clara, organizada y visualmente atractiva, destacando mi perfil como Ingeniera de Sistemas y Telecomunicaciones.

El sitio permite visualizar información relacionada con:

- Perfil profesional.
- Experiencia laboral.
- Formación académica.
- Formación complementaria.
- Habilidades técnicas y profesionales.
- Tecnologías y herramientas.
- Proyectos desarrollados.
- Información de contacto.

---

## 🚀 Tecnologías utilizadas

El proyecto fue desarrollado utilizando las siguientes tecnologías y herramientas:

- **HTML5:** Estructura y organización del contenido.
- **CSS3:** Diseño visual, estilos y diseño responsive.
- **JavaScript:** Funcionalidades interactivas y comportamiento dinámico.
- **EmailJS:** Integración del formulario de contacto para el envío de mensajes directamente al correo electrónico.
- **Font Awesome:** Implementación de iconos en las diferentes secciones del sitio.
- **Git:** Control de versiones del proyecto.
- **GitHub:** Almacenamiento y gestión del código fuente.

## 📧 Sistema de contacto

El portafolio cuenta con un formulario de contacto integrado mediante **EmailJS**.

Esta funcionalidad permite que los visitantes escriban y envíen un mensaje desde el sitio web, el cual es enviado directamente al correo electrónico configurado en EmailJS.

El sistema permite recibir información como:

- Nombre del visitante.
- Correo electrónico.
- Asunto.
- Mensaje.
